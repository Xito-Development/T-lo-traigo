# Plantillas de correo (Supabase → Authentication → Emails → Templates)

Copia el **asunto** y pega el contenido del archivo en **Message body** (pestaña «Source»).

| Plantilla de Supabase | Archivo | Asunto |
|---|---|---|
| Confirm sign up | `confirm-signup.html` | Tu código de T lo traigo |
| Reset password | `reset-password.html` | Código para cambiar tu contraseña |
| Magic link or OTP | `magic-link.html` | Tu código para entrar en T lo traigo |
| Change email address | `change-email.html` | Confirma tu nuevo correo |
| Invite user | `invite.html` | Te han invitado a T lo traigo |
| Reauthentication | `reauthentication.html` | Confirma que eres tú |

Las imágenes se cargan desde `https://tlotraigo.unocerobits.com/email/` (sube la carpeta `web/t-lo-traigo/email/`).
